### Section: FAQ
**Frequently asked questions**

**Is this the official California state board website?**  
No. This is an independent exam-prep resource. It is not affiliated with, endorsed by, or operated by the California Board of Barbering and Cosmetology or any government agency.

**Is this only for the written cosmetology exam?**  
Yes. This version is focused on written-exam prep for California cosmetology students.

**Do I need a textbook to use it?**  
No. It is designed to work as a standalone prep tool, though some students may still like using it alongside school materials.

**Does it include practice questions and explanations?**  
Yes. Practice questions and answer explanations are a core part of the product.

**Can I use it on my phone?**  
Yes. The study format is meant to be simple and mobile-friendly.

**Who is this best for?**  
It is especially useful for students who want a more organized study path, repeat test takers, and anyone who tends to lose time bouncing between scattered resources.
