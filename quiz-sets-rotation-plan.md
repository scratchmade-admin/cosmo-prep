# Quiz Sets Rotation Plan

This plan is designed for Melissa's California cosmetology written-exam prep.

## Goal
Keep practice fresh without making each day feel random. The rotation should repeat core safety material often, while still touching haircutting, styling, shampooing, skin/nails, and science.

## Study Rhythm
- **5 study days per week** works well for steady prep.
- **10 questions per set** keeps the workload light enough for near-daily use.
- **2 sets per day** is a strong target on normal days.
- On busy days, do **1 set only**, then review explanations.

That gives:
- 20 questions on a normal study day
- 100 questions across a 5-day week if Melissa does two sets daily
- enough repetition to build speed without staring at the same exact mix every day

## Core Rotation Structure
Use the 60-question rotation bank as six 10-question sets:

- **Set A - Sanitation Core**
- **Set B - Law and Professional Safety**
- **Set C - Chemical Services Core**
- **Set D - Hair Fundamentals and Analysis**
- **Set E - Mixed Procedures**
- **Set F - Mixed Review and Pressure Check**

## Suggested Weekly Rotation
### Week pattern
- **Day 1:** Set A + Set D
- **Day 2:** Set B + Set C
- **Day 3:** Set E + Set A
- **Day 4:** Set C + Set F
- **Day 5:** Set B + Set D

Why this works:
- sanitation appears often because it is heavily tested and easy to miss through overconfidence
- law/safety repeats often because safe judgment drives many exam questions
- chemical services gets multiple appearances because it is high-volume and easy to confuse
- hair fundamentals supports better answers in color, texture, heat, and scalp questions
- mixed days help Melissa shift between topics the way the real written exam does

## 3-Week Rotation Cycle
### Week 1: Learn
- Move through the sets in the normal order
- Focus on accuracy and reading explanations
- Do not rush timing yet

### Week 2: Recall
- Reuse the same six sets, but shuffle question order inside each set
- Answer first, then mark weak topics
- Re-study any missed sanitation, law, or chemical questions the same day

### Week 3: Pressure
- Use mixed pairs only: A+C, B+F, D+E, A+F, C+E
- Try to answer a 10-question set in about 10 to 12 minutes
- Review every missed question out loud in plain language

Then restart the cycle.

## Simple Rules for Building Daily Sets
When pulling from the 60-question JSON bank:
- include **at least 3 sanitation or law/safety questions** in every 10-question set
- include **at least 2 chemical-services questions** in most sets
- include **1 to 2 hair fundamentals questions** regularly
- add **1 wildcard question** from haircutting, styling, shampooing, skin/nails, or chemistry terms
- avoid repeating the exact same 10-question set on back-to-back days

## Retake Rules
If Melissa misses a question:
- review the explanation immediately
- see that question again within **48 hours**
- if she misses it twice, place it into the next mixed review set
- if she misses it three times, move it into a short "trouble spots" list for daily repetition until it sticks

## Priority Topics to Repeat Most Often
These should show up the most across the rotation:
1. sanitation and infection control
2. law, scope, contraindications, and safe refusal
3. chemical safety, patch tests, strand tests, and overprocessing
4. hair structure, porosity, elasticity, and pH
5. thermal and procedural safety

## Best Use for Melissa
A practical routine would be:
- first set in the morning or before work
- second set later in the day
- quick review of only missed questions at night

If time is tight, one clean 10-question set with explanation review is still worth doing. Consistency beats marathon sessions.

## Bottom Line
This rotation is meant to keep core exam topics in circulation almost daily, especially safety-heavy material, while still giving enough variety to prevent memorizing the order instead of learning the content.
