# Website Plan: California Cosmetology State Board Prep

## Goal
Build a California-focused cosmetology exam prep website that gives a student everything needed to prepare for the written state board exam in one place.

The site should help a student:
- learn the material clearly
- practice under test-like conditions
- identify weak areas fast
- review the highest-value topics efficiently
- feel less overwhelmed and more prepared on exam day

## Positioning
Working promise:
- California-focused
- built for the written cosmetology exam
- simple, practical, and mobile-friendly
- designed to help students study smarter, not just longer

Important legal/positioning note:
- Do not claim to be the official California board
- Do not imply endorsement by the state
- Present it as independent exam prep

Suggested headline:
- Pass the California Cosmetology Written Exam With a Clear Study Plan

Suggested subhead:
- Study the right material, take realistic practice tests, and focus on the topics that matter most.

## Audience
Primary audience:
- California cosmetology students preparing for the written licensing exam

Secondary audience:
- licensed professionals helping a spouse, child, or employee study
- repeat test takers who need structure and confidence

## Core Product Structure
The strongest version of this website has five pillars:

1. Study Guide
- topic-by-topic lessons
- plain-English explanations
- California-specific safety and law emphasis

2. Practice Tests
- short quizzes by topic
- timed mixed exams
- full mock tests
- instant scoring with explanations

3. Focused Drills
- weak-area drills for sanitation, chemical services, and law
- repeat until mastery model

4. Cram Tools
- flashcards
- one-page cheat sheets
- 3-day and 7-day cram plans

5. Progress Tracking
- completed modules
- quiz scores
- weak-topic flags
- recommended next step

## Best MVP
If building fast, the minimum viable version should include:
- homepage
- study guide broken into 8 core modules
- 200 to 400 practice questions
- answer explanations
- one full mock test
- 3-day cram plan
- 7-day study plan
- disclaimer and FAQ

That is enough to be real.

## Practice Experience Design
### Quiz Types
- 10-question quick checks
- 25-question topic drills
- 50-question mixed review tests
- 100-question mock exams

### Feedback Model
For each question, show:
- correct answer
- short explanation
- why the other choices are wrong when useful
- category tag

### Score Banding
- 90 to 100: test-ready
- 80 to 89: close, tighten weak spots
- 70 to 79: needs focused review
- below 70: rebuild fundamentals before retesting

## Monetization Options
### Option A: Single purchase
- one-time fee for full access
- simplest offer

### Option B: Subscription
- monthly access
- works better if expanding into multiple states or licenses

### Option C: Free + paid upgrade
- free sample quiz and one module
- paid full access for all lessons, tests, and cram tools

Best starting option:
- free sample plus one-time paid full access

## Trust Builders
- clear California scope
- practical explanations
- realistic exam-style questions
- mobile-friendly design
- student testimonials once available
- visible disclaimer that this is independent prep, not official state material

## Features to Add Later

## Content Standards
Every lesson should be:
- short enough to finish in one sitting
- specific to likely exam content
- written in plain language
- focused on safe practice and correct reasoning

Every quiz should:
- avoid trick wording unless teaching test-reading
- reinforce sanitation, safety, scope, and chemical caution
- explain the logic, not just the answer

## Homepage Conversion Flow
1. Clear promise
2. Explain what is included
3. Show study path
4. Offer free sample test
5. Show CTA to start studying
