# Launch Plan

## Phase 1: Fast MVP
Build first:
- homepage
- 8 written modules
- 50 free sample questions
- 200 paid questions
- answer explanations
- 1 full mock exam
- FAQ, disclaimer, pricing page

## Phase 2: Better Learning Experience
Add:
- user accounts
- progress tracking
- weak-area tagging
- flashcards
- printable cram sheet
- timed mode

## Phase 3: Expansion
Add:
- esthetician version
- nail tech version
- barber version
- Spanish translation
- email reminders
- mobile app layer if demand is real

## Suggested Stack
Simple, fast stack options:
- Webflow for quick marketing pages + quiz embed
- Next.js for a custom product
- Supabase or Firebase for auth, scores, and question progress
- Stripe for checkout if monetized

Best choice if moving seriously:
- Next.js + Supabase + Stripe

Best choice if testing demand this week:
- no-code homepage + basic quiz platform + simple checkout

## First Validation Path
Before overbuilding:
1. Put up a simple landing page
2. Offer a free sample quiz
3. Collect emails or signups
4. Ask early users where they struggle most
5. Build more question banks based on real demand

## What Success Looks Like
Short term:
- first 10 users complete sample quiz
- early feedback confirms questions feel useful
- students ask for more tests and explanations

Medium term:
- paid conversions from free quiz
- repeat usage over several study sessions
- demand for more California license tracks
